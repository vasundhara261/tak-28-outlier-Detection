 Task 28 – Outlier Detection

## Objective
To identify potential outliers in an employee salary dataset using box plot visualization.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Description
This project focuses on detecting unusual values in numerical data using a box plot. An employee salary dataset was created and analyzed using Python.

## Methodology
1. Imported Python libraries.
2. Created an employee salary dataset.
3. Performed descriptive statistical analysis.
4. Visualized salary distribution using a box plot.
5. Applied the Interquartile Range (IQR) method.
6. Identified potential outliers.

## Key Findings
The analysis identified ₹2,00,000 as a potential salary outlier compared with the other observations.

## Conclusion
Box plot visualization and the IQR method help identify unusual observations in numerical datasets. Outliers should be investigated before removal.

## Learning Outcome
Learned how to visualize numerical data and identify potential outliers using statistical techniques.
